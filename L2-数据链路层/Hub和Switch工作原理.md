# Hub 和 Switch 工作原理

## 三层架构

什么是拓扑，什么是拓扑分类，拓扑分类是用来定义什么的？

- **接入层** 楼层交换机，Layer 2 Switch，连接 PC
- **汇聚层** 高大上的 MLS(Multi Layer Switch) 多层交换机 级联汇总接入层

以上两层组成一个被称为交换区块区域。

- **核心层** 最牛逼的交换机 级联汇总汇聚层

最早的时候，在交换机问世前，园区网使用的是交换机的前身 Hub 集线器，在路由交换环境中，交换机和路由器的定位就是接入设备。
所谓接入设备，顾名思义用接入设备就是直接连接终端的。
当然，前提是你没有部署无线，如果你部署无线，那么接入设备直接连线，连到 AP(Access Point)。AP 释放无线信号，让我们的 PC 终端去做一个关联。
企业网大规模部署 AP 要部署瘦 AP，不用一台一台从 Console 口登录胖 AP，而是通过无线控制器 AC(Access Controller) 来配置。

接入层设备说是2层交换机，但是也具备3层功能，交换机有接口能够起 IP，这些我们称为弱3层功能。
3层功能对于交换机来说分成两类。1类叫弱3层，1类叫强3层。
所谓强3层，就是说交换机能实现大部分路由器的功能。比如，能做 VLAN 间通信，运行各种路由选择协议，ACL 访问控制。
你会发现这些强3层网络设备确实也能配置 IP 地址，看起来好像具备三层的功能，
但是事实上，给接入设备接口配置 IP 地址的目的，仅仅是为了使用 Telnet SSH 远程登录交换机，这些登录的落脚点接口叫做 SVI(Switch VLAN Interface)

## 拓扑分类

拓扑(Topology) 网络连接图。
拓扑分类，网络通过什么样的方式连，它会具备一些什么样的工作原理。

拓扑分类一共分为四类：

- 总线型网络
- 环形网络
- 星型网络

以上三种是关于网络接入拓扑的。

还有一种用于广域网连接拓扑的，互联网络(部分互联，全互联)。

## LAN 和 WAN 协议

Ethernet 以太网，是一个 LAN 局域网，双绞线 光纤 同轴电缆，

- LAN 局域网协议：Ethernet Token Ring FDDI
- WAN 广域网协议：HDLC PPP FrameRelay Serial 线缆 以前老大，现在光纤远超它。

Protocol 协议：就是网络中的规则，网络中的规矩。所有生产网络设备的厂商，是不能随着性子来生产的，必须按照一定的规则来生产。
网络和交通一样，必须遵循交通法规。才能避免车祸。

Protocol Suit：OSI TCP/IP IPX/SPX AppleTalk ATM

Ethernet 以太网 最早使用双绞线连接，传输距离 100 米，后来支持光纤(多模光纤，单模光纤) 传输距离 1000KM。
因此在当前这个时代已经不在强调局域网和广域网这个概念了，以太网统一江湖

运营商最大的收入就是专线和 VPN，不是自己做的 IPSec，而是运营商 VPN MPLS。

## Hub 集线器

Hub Layer 1 属于一个一层设备，属于物理层设备，傻瓜式设备。

### 带宽 Bandwidth

1秒内通过网络某一节点(Node，一个节点就是一个3层网络接口)能接收和发送多少 bit 的数据。10Mbit/s 100Mbit/s 1000Mbit/s。
什么是一个三层接口，计算机网卡接口，路由器的大多数接口，只要能配置 IP 地址就是一个三层接口。
在网络中一个节点不是一台设备，而是一个接口本身。

### bit 和 Byte

计算机中数据的最小表示单位是 bit。一个 bit 上可以存放一个 0 或者一个 1。

bit Kbit Mbit 它们之间的关系是乘以 1000。

Byte 字节 一个字节由 8 个 bit 位组成。Byte KByte MByte GByte，它们之间的关系是 2 的 10 次方 1024。

因此带宽 10Mbit 和 10MByte 完全是两码事。10M 带宽也就 1M 的下载速度。

### 共享带宽

最先进的集线器只能提供 10Mbit/s 的带宽，并且是所有接口加起来一共的量。叫做共享带宽。连接几个终端就几个机器分享 10M 带宽。
