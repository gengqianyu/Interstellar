# Loopback

**Loopback** 回环接口，是一个虚拟网卡，可以配置 IP，一般 IP 地址会配置为 **127.0.0.1**。

多用于测试，充当服务器网接收目的 IP 地址是 127.0.0.1 的数据帧。

也可以利用 **nginx** 为 127.0.0.1 绑定任意个虚拟域名，使其看起来更像真实的服务器。

本地测试一般会设置 127.0.0.1 的 DNS，使请求任意虚拟域名时将数据发送到配置有 127.0.0.1 IP 地址的回环接口。

---

**监听**就是应用层服务为自己分配一个端口号（相当于服务 ID），并监听一个配置了相应 IP 地址的网卡，所有目的 IP 是本网卡配置的 IP 地址的流量都会进来，并到达 L4 层，再由端口号区分流量要给 L5 应用层哪个应用服务。
